# NoAbsTube

Адаптивная одностраничная витрина для поиска видео и плейлистов.

## Запуск

Открой `index.html` в браузере или запусти локальный сервер в этой папке, например:

```sh
python -m http.server 8000
```

Автор идеи: [@XXXfaraon4cik](https://t.me/XXXfaraon4cik). Владелец проекта: [@Temperskiy](https://github.com/Temperskiy).

Поиск видео открывает результаты YouTube. Поиск плейлистов открывает Spotify, а ссылку на плейлист можно вставить в официальный плеер на странице.

История последних поисков хранится только локально в браузере. Её можно очистить в разделе «Недавнее».

## Важно

- NoAbsTube не удаляет, не скрывает и не блокирует рекламу. Условия рекламы задают YouTube и Spotify.
- NoAbsTube — независимый проект, не являющийся официальным продуктом YouTube или Spotify.
- Доступность контента и воспроизведения зависит от региона, возраста, аккаунта и правил самих платформ.
- Если сервис просит войти, вводи данные только на официальном сайте или в приложении. Не вводи пароль в NoAbsTube.
- При переходе на сторонние платформы действуют их настройки конфиденциальности; видео и музыка могут расходовать мобильный интернет.
- Пользуйся сервисами с учётом их условий и подходящих тебе возрастных настроек.

## Публикация на GitHub Pages

Создай репозиторий и загрузи содержимое этой папки в его корень. В настройках репозитория открой **Pages**, выбери публикацию из ветки `main` и папки `/ (root)`. GitHub покажет адрес опубликованного сайта.
